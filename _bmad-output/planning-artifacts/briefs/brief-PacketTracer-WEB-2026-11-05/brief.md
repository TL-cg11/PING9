# 제품 브리프: PacketTracer WEB (작업명)

빠른 경로로 작성한 초안입니다. 사용자가 직접 말하지 않은 내용은 `[가정]`으로 표시했습니다. 근거 번호 `[n]`은 `docs/project-plan/01-technical-validation.md`의 출처 번호입니다.

## 요약

PacketTracer WEB은 설치 없이 웹 브라우저에서 네트워크 장비를 배치하고 연결해, 구성과 동작을 실습하는 학습용 네트워크 시뮬레이터입니다. 수업이나 스터디에서 수강생 수십 명이 각자 계정으로 접속해 쓰는 것을 목표로 합니다.

네트워크 동작은 서버가 아니라 수강생의 브라우저 안에서 계산합니다. 프로토콜 동작을 직접 구현한 시뮬레이션 엔진을 쓰므로 서버 비용이 거의 들지 않고, 패킷이 장비를 지나는 과정을 한 단계씩 멈춰 가며 보여 줄 수 있습니다.

2인 팀이 4주 안에 MVP를 만듭니다. MVP는 Switch, Router, PC로 토폴로지를 만들고 VLAN과 Static Routing을 설정한 뒤 ping으로 확인하는 실습까지를 다룹니다.

## 문제

- Cisco Packet Tracer는 Cisco Networking Academy와 관련된 용도로만 쓸 수 있습니다. Networking Academy와 무관한 수업에서 쓰려면 Cisco의 서면 승인이 필요합니다 [28].
- `[가정]` 설치형 프로그램은 수강생마다 설치와 계정 등록을 거쳐야 해서 수업 첫 시간을 잡아먹고, 기기에 따라 설치가 안 되는 경우가 생깁니다.
- GNS3 같은 에뮬레이터는 실제 장비 이미지와 서버 자원이 필요해 입문 수업에 쓰기 무겁습니다 [13][27].

## 해결 방식

브라우저 주소만 열면 바로 실습할 수 있습니다.

- 장비를 캔버스에 끌어다 놓고 포트끼리 연결합니다.
- 장비를 눌러 콘솔을 열고, 수강생이 교재에서 배운 계층형 명령어로 IP, VLAN, 경로를 설정합니다.
- PC에서 `ping`을 실행하면 패킷이 링크를 따라 이동하는 모습과 장비별 처리 내역이 보입니다. 멈춤과 다음 단계로 한 단계씩 따라갈 수 있습니다.
- 통신이 안 되면 어느 장비에서 왜 버려졌는지 알려 줍니다.
- 토폴로지를 계정에 저장하고 다시 불러옵니다.

## 차별점

기술적 해자는 없습니다. 차이는 사용 조건과 학습 경험에 있습니다.

- **설치와 라이선스 제약이 없습니다.** 브라우저만 있으면 되고, Cisco의 소프트웨어·이미지·아이콘을 쓰지 않습니다.
- **패킷 처리 과정을 설명합니다.** 시뮬레이션 방식이어서 각 장비가 왜 그렇게 판단했는지를 단계마다 보여 줄 수 있습니다.
- **운영 비용이 거의 없습니다.** 계산이 각자 브라우저에서 일어나 수강생이 늘어도 서버 부하가 늘지 않습니다.

단점도 분명합니다. 구현한 기능만 동작하며, 실제 장비와 세부 동작이 다를 수 있습니다. Cisco Packet Tracer도 같은 한계를 스스로 밝힙니다 [1].

## 사용자

역할 구분이 없습니다. 로그인한 사람은 모두 같은 기능을 씁니다.

- **사용자**: 네트워크를 배우는 사람. `[가정]` IP 주소, 서브넷, 스위치와 라우터의 차이를 막 배우는 입문 단계이며, 교재의 실습을 직접 따라 해 보려 합니다.

## 성공 기준

`[가정]` 팀이 정한 수치가 없어 아래를 제안합니다.

- 화이트보드의 예시 토폴로지(Router 2대, Switch 2대, PC 2대)를 처음 쓰는 수강생이 15분 안에 구성해 양 끝 PC 사이의 ping에 성공한다.
- 수강생 30명이 동시에 써도 서버가 멈추지 않는다.
- 4주 안에 MVP를 배포하고 시연한다.
- ping 실패 시 원인이 되는 장비와 사유를 화면에서 찾을 수 있다.

## 범위

| MVP에 넣는 것 | MVP에서 빼는 것 |
|---|---|
| 토폴로지 편집 (장비 배치·삭제·연결) | 강사 역할, 수업(반), 과제 배포·채점 (만들지 않음) |
| 장비: Switch, Router, PC | Firewall, L3 Switch (3차) |
| 장비 콘솔과 계층형 CLI | Dynamic Routing, NAT, DHCP (2차) |
| Switching, ARP, VLAN, Static Routing, ICMP ping | VPN (3차) |
| 패킷 이동 표시, 이벤트 목록, 단계별 재생 | 서버 에뮬레이션 장비 연동 (3차 검토) |
| 소셜 로그인, 토폴로지 저장·불러오기 | 여러 사람이 한 토폴로지를 동시에 편집 |
| 오류 피드백 | Cisco 파일 형식(.pkt) 가져오기 |

VLAN은 MVP 목표이지만, 1주차 구현 속도가 느리면 가장 먼저 2차로 미룹니다.

## 비전

4주 뒤에는 입문 실습용 도구입니다. 그 뒤로 Dynamic Routing과 NAT를 더해 한 학기 네트워크 수업의 실습을 대부분 다룹니다. 실제 라우팅 소프트웨어(FRRouting)로 동작하는 장비를 함께 쓸 수 있게 할지는 메모리와 격리를 실측한 뒤 결정합니다.

## 가정과 미결정

- `[가정]` 공개용 제품 이름은 따로 정합니다. "PacketTracer WEB"은 작업명입니다 [30].
- `[가정]` 화이트보드의 동그라미 친 "L3"는 L3 Switch를 뜻합니다.
- 미결정: 2인의 역할 분담, 배포 위치, 개발 스택.
