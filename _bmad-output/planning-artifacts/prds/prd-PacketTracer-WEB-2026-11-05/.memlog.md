- (decision) PRD 본문 위치는 docs/project-plan/02-requirements.md(사용자 지시). 작업 공간의 prd.md는 위치 표시만 둠 — 내용 중복 방지
- (decision) 작업 방식: 빠른 경로. 사용자가 상세 명세를 요청했고 범위 질문 3건에 답함. 시나리오 인물·수치는 [가정]으로 표시
- (decision) D9 엔진=브라우저 시뮬레이션, D10 MVP 역할 없음(학습자만), D11 패킷 흐름=이동 표시+이벤트 목록+단계별 재생, D12 소셜 로그인
- (decision) MVP FR-1~FR-47: 계정, 토폴로지 관리, 편집기, 장비(PC·Switch 8포트·Router 4포트), CLI, IP 설정, Switching·ARP·루프 보호, VLAN(access·trunk), Static Routing·ICMP 오류, ping, 추적·재생, 상태 표시, 오류 피드백
- (decision) 일정이 밀릴 때 줄이는 순서: 예제·내보내기 → 테이블 패널 → 재생의 이전 단계·속도 → trunk → VLAN 전체. 사용자가 단계별 재생을 MVP에 넣었으므로 작업량이 늘어난 데 대한 안전장치
- (assumption) A1~A11(02 문서 2.11절): 학습자 수준, 포트 이름, Router 인터페이스 기본 꺼짐, 각종 한도·타이머, 영어 CLI+한국어 오류 설명, 성능·성공 지표 수치, L3=L3 Switch
- (event) 생략한 절차: 입력 대조(reconciliation), 검토자 점검(rubric), 문체 다듬기. 사용자 검토 게이트에서 대기. status=draft 유지
- (change) D10 변경: 강사·수업·과제 기능은 이후 단계 포함 만들지 않음. UJ-6과 강사 흐름도 삭제, 용어 '학습자'→'사용자', 비목표에 추가, Q6 해소
- (decision) 3단계 질문 답변: 백엔드=얇은 자체 API 서버, 배포 위치=추천받기, 소셜 로그인 제공자=Google (Q1 해소)
