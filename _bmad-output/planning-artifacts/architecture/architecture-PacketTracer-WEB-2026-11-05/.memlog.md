- (decision) 상태 3분할: Document(저장, engine reducer 소유) / Runtime(MAC·ARP·가상 시계·CLI 세션, kernel 소유, 저장 안 함) / UI(선택·콘솔·재생 커서, web store 소유)
- (decision) 결정성: 가상 시계와 (time, seq) 사건 큐. 엔진 안에서 Date.now·Math.random·setTimeout 금지. ID와 MAC 주소는 엔진 밖에서 만들거나 결정적으로 유도. 근거 NFR-11, 재생·테스트의 전제
- (decision) CLI: 선언적 명령 트리 하나에서 파싱·축약·자동완성·도움말·running-config 직렬화를 모두 생성. 막는 분기: 도움말과 파서 불일치, show running-config 왕복 실패
- (decision) 저장: 토폴로지를 JSONB 문서 통째로 저장 + revision 낙관적 잠금(409). 대안=장비·링크 정규화 테이블(기각: 엔진이 문서 전체를 쓰고, 교차 조회 요구가 없음). Q3(두 탭 편집) 해소
- (decision) 백엔드: Hono + Node 24 LTS, better-auth(Google), Drizzle + PostgreSQL. 대안=Fastify(동등, 성숙), NestJS(과함), arctic 직접 구현(기각: 2026-07 폐기 표시), Prisma(기각: latest 태그가 RC)
