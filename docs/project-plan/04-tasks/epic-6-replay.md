# E6. 패킷 흐름을 재생하며 본다 — 작업 상세

- 상위 문서: [04-development-plan.md](../04-development-plan.md)
- 수용 기준: [epics.md](../../../_bmad-output/planning-artifacts/epics.md)의 Epic 6
- 합계: Story 5개, Task 8개, 약 11.0인일 (🟡 추정)
- 선행 Epic: E1 (Trace, 이벤트 목록). 엔진이 없어도 `shared`의 예시 Trace로 개발할 수 있음. Story 6.1과 6.2는 E1만 있으면 됨. Story 6.4는 E3의 T3.3.2(포트 끄기), Story 6.3과 6.5의 Router 부분은 E4가 끝난 뒤에 확인
- 우선순위: 일정이 밀리면 Story 6.5, 그다음 6.2의 이전 단계와 속도 조절을 줄입니다

프레임이 링크를 따라 움직이는 모습을 캔버스에서 보고, 단계별로 재생하고, 프레임 내용과 장비 테이블과 포트 상태를 본다. 재생은 완성된 Trace를 읽기만 하며 엔진을 호출하지 않는다 (AD-6).

표 읽는 법과 공통 완료 조건은 [개발 계획 4.3절](../04-development-plan.md#43-분해-구조-읽는-법)에 있습니다.
