# E4. Router로 네트워크를 잇는다 — 작업 상세

- 상위 문서: [04-development-plan.md](../04-development-plan.md)
- 수용 기준: [epics.md](../../../_bmad-output/planning-artifacts/epics.md)의 Epic 4
- 합계: Story 4개, Task 10개, 약 10.5인일 (🟡 추정)
- 선행 Epic: E1 (ARP, IPv4 호스트 처리, ICMP echo), E3의 Story 3.1, 3.3, 3.4 (CLI 모드, 인터페이스 모드와 포트 상태, `show running-config` 직렬화). Story 3.2와 3.5(축약, 도움말, 오류 표시)는 없어도 진행할 수 있음

Router를 놓고 인터페이스에 IP를 설정하고 Static route를 넣어, 서로 다른 네트워크의 PC끼리 통신한다.

표 읽는 법과 공통 완료 조건은 [개발 계획 4.3절](../04-development-plan.md#43-분해-구조-읽는-법)에 있습니다.

### Story 4.4 경로가 없거나 TTL이 다하면 알 수 있다

| ID | 작업과 세부 작업 | 영역 | 선행 | 완료 기준 | 테스트 방법 | 난이도 | 추정 |
|---|---|---|---|---|---|---|---|
