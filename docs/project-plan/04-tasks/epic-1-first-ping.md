# E1. 첫 ping — 작업 상세

- 상위 문서: [04-development-plan.md](../04-development-plan.md)
- 수용 기준: [epics.md](../../../_bmad-output/planning-artifacts/epics.md)의 Epic 1
- 합계: Story 12개, Task 34개, 약 37.0인일 (🟡 추정)

로그인 없이 브라우저에서 PC와 Switch를 놓고 연결해 ping하고, 이벤트 목록과 실패 사유를 본다. 이 Epic 동안 토폴로지는 브라우저 메모리에만 있다.

표 읽는 법과 공통 완료 조건은 [개발 계획 4.3절](../04-development-plan.md#43-분해-구조-읽는-법)에 있습니다. "선행"이 "없음"이면 바로 시작할 수 있습니다.
