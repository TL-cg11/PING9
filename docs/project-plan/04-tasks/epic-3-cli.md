# E3. 장비를 명령어로 설정한다 — 작업 상세

- 상위 문서: [04-development-plan.md](../04-development-plan.md)
- 수용 기준: [epics.md](../../../_bmad-output/planning-artifacts/epics.md)의 Epic 3
- 합계: Story 5개, Task 11개, 약 11.0인일 (🟡 추정)
- 선행 Epic: E1 (명령 트리 기반 T1.6.1, 콘솔 화면 T1.6.2, Switch 모델 T1.7.3)

Switch의 콘솔에서 계층형 CLI를 쓴다. Router는 E4에서 같은 명령 트리를 이어 쓴다. E4와 E5가 이 Epic의 Story 3.1, 3.3, 3.4에 기대므로 이 셋을 먼저 끝낸다. Story 3.2와 3.5(축약, 도움말, 오류 표시)는 E4·E5와 동시에 진행할 수 있다.

표 읽는 법과 공통 완료 조건은 [개발 계획 4.3절](../04-development-plan.md#43-분해-구조-읽는-법)에 있습니다.
