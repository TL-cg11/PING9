## 0.2 화이트보드 항목 분류

화이트보드에 적힌 항목은 전부 **계획 단계**입니다. 구현된 것도, 기술적으로 검증된 것도 없습니다.

| 분류 | 화이트보드 항목 | 구현 여부 | 검증 상태 | 비고 |
|---|---|---|---|---|
| 방향 | Network Simulator, web 기반 | 미구현 | 계획만 존재 | Packet Tracer에 별표, "Simulator"에 박스 표시 |
| 방향 | 언어: ? | — | ❓ 미결정 | 스택 제약 없음. 3단계에서 추천 |
| 비교 대상 | VMware (Virtual) | — | 배제로 읽힘 | X 표시 |
| 비교 대상 | GNS3 (emulator, Qemu 기반) | — | ⚠️ 미검증 | "emulator"에 X 표시. 1단계에서 검증 |
| 장비 | Router | 미구현 | 계획만 존재 | |
| 장비 | Switch (Cisco L2, 8 Port) | 미구현 | 계획만 존재 | |
| 장비 | VPC (가상 PC) | 미구현 | 계획만 존재 | |
| 장비 | Firewall (iptables) | 미구현 | 계획만 존재 | 동그라미 = 후순위 |
| 소프트웨어 | VyOS 1.3.5 | — | ⚠️ 미검증 | 적용 가능성, 라이선스, 자원 소비를 1단계에서 검증 |
| 기능 | Static Routing | 미구현 | 계획만 존재 | 체크 = 우선 |
| 기능 | Dynamic Routing | 미구현 | 계획만 존재 | |
| 기능 | L2, VLAN | 미구현 | 계획만 존재 | |
| 기능 | ping, ipconfig 등 명령어 | 미구현 | 계획만 존재 | |
| 기능 | NAT | 미구현 | 계획만 존재 | |
| 기능 | VPN | 미구현 | 계획만 존재 | 동그라미 = 후순위 |
| 기능 | L3 | 미구현 | 계획만 존재 | 동그라미 = 후순위. 🟡 L3 Switch를 뜻하는 것으로 가정 |
| 예시 | Router 2대 + Switch 2대 + PC 2대 토폴로지 | 미구현 | 계획만 존재 | MVP 시연 시나리오 후보 |

🟡 **가정**: 동그라미 친 "L3"는 L3 Switch(스위치에서 VLAN 간 라우팅)를 뜻한다고 읽었습니다. Router의 L3 기능 자체는 Static Routing에 체크가 있으므로 우선 범위입니다. 해석이 다르면 알려 주세요.

## 0.3 확정된 결정

2026-11-05 질의응답으로 확정한 사항입니다.

| # | 항목 | 결정 | 계획에 미치는 영향 |
|---|---|---|---|
| D1 | 팀 규모 | ✅ 3인 (2026-11-05 정정. 처음에는 2인으로 적었음). 분담은 팀이 나중에 정함 | 병렬 작업 흐름이 최대 3개. 계획의 담당은 사람이 아니라 영역으로 표기 |

| D3 | 4주의 범위 | ✅ MVP만. 2차·3차는 마감 이후 로드맵 | 4주 안의 일정표는 MVP만 다룹니다 |
| D4 | 사용 대상 | ✅ 수업·스터디용. 수십 명이 각자 계정으로 실습. 역할 구분 없이 모두 같은 기능을 사용 | 인증, 사용자별 데이터 분리, 동시 사용 수십 명 규모가 필요합니다 |
| D5 | 배포 예산 | ✅ 거의 없음. 무료 호스팅, 팀원 PC, 소형 서버 1대 수준 | 서버 자원을 많이 쓰는 방식에 불리합니다 |
| D6 | 우선순위 표시 | ✅ 체크(Static Routing) = 우선, 동그라미(Firewall·VPN·L3) = 후순위 | MVP 범위 설정의 기준 |
| D7 | 산출물 위치 | ✅ `docs/project-plan/` 아래 주제별 Markdown | |
| D8 | 이번 단계 범위 | ✅ 문서만 작성. 코드와 실행 환경은 수정하지 않음 | |

## 0.5 초기 요구사항 목록 (요청문 기준)

화이트보드와 요청문에서 나온 요구사항입니다. 단계별 범위(MVP·2차·3차)는 4단계 문서에서 정합니다.

- [ ] 웹 기반 토폴로지 편집기 (장비 배치, 연결)
- [ ] 장비 종류: Router, Switch, VPC, Firewall
- [ ] 장비별 CLI 또는 콘솔
- [ ] 네트워크 명령어: ping, ipconfig 등
- [ ] L2 기능: Switching, VLAN
- [ ] L3 기능: Static Routing, Dynamic Routing
- [ ] NAT
- [ ] VPN
- [ ] 패킷 흐름 표시, 장비 상태 표시
- [ ] 구성 저장 및 불러오기
- [ ] 오류 피드백
- [ ] 계정 (역할 구분 없음)
