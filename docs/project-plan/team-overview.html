프로젝트 소개

수업과 스터디에서 쓰는 웹 기반 네트워크 시뮬레이터입니다. Cisco Packet Tracer와 비슷한 학습 경험을 주되, 코드와 화면은 모두 독자적으로 만듭니다.

사용자가 해결하려는 일

  • 교재의 실습 예제를 설치 없이 바로 따라 해 보고 싶다.
  • 설정한 대로 통신이 되는지 확인하고, 안 되면 어디가 틀렸는지 알고 싶다.
  • 패킷이 스위치와 라우터에서 어떻게 처리되는지 눈으로 보고 싶다.
  • 하던 실습을 저장해 두고 다른 날, 다른 기기에서 이어서 하고 싶다.

만들지 않는 것

  • 실제 장비와 완전히 같은 동작. 구현한 범위의 동작만 보장합니다.
  • 강사 역할, 수업, 과제 기능. 로그인한 사람은 모두 같은 기능을 씁니다.
  • 여러 사람이 한 토폴로지를 동시에 편집하는 기능.
  • Cisco의 파일 형식(.pkt), 아이콘, 화면, 문구. IPv6와 모바일 화면.
현재 상태: 저장소에 애플리케이션 코드가 없는 신규 프로젝트입니다. 화이트보드에 적힌 항목은 전부 계획 단계이며, 구현되거나 직접 실행해 검증한 것은 없습니다.

성공한 뒤 실습을 이어 갈 때는 장비 배치 단계로 돌아갑니다.

계획서의 사용자 시나리오 다섯 개

처음 접속해 첫 ping에 성공한다

Switch 1대와 PC 2대를 놓고 연결한 뒤 IP를 넣고 ping. 한쪽에 IP가 없으면 그 사유가 표시됩니다.

VLAN으로 네트워크를 나눈다

같은 VLAN끼리는 통신되고 다른 VLAN으로는 실패합니다. trunk로 Switch 사이를 잇습니다.

Router 2대로 두 네트워크를 잇는다

경로가 없어 실패하는 것을 본 뒤, ip route로 경로를 넣어 성공시킵니다.

단계별 재생으로 원인을 찾는다

응답이 R2에서 멈춘 것을 따라가서, 돌아오는 경로를 빠뜨린 것을 알아챕니다.

다른 기기에서 이어서 한다

자동 저장된 토폴로지를 집에서 열어 이어 하고, 파일로 내보내 스터디원에게 보여 줍니다.

읽을 때 주의할 점

가정 시나리오의 인물과 상황은 작성 중에 가정한 것입니다. 실제 사용 모습과 다르면 고쳐야 합니다.

화이트보드에 적힌 기술의 검토 결과

  • VyOS 1.3.5: 쓰지 않습니다. 1.3.x 계열은 지원이 끝났고, 지원되는 1.4 이상은 문서상 최소 사양이 인스턴스당 RAM 4GB입니다.
  • GNS3, containerlab: 배제. 신뢰할 수 있는 운영자를 전제로 한 도구라 여러 사용자에게 그대로 열 수 없습니다.
  • Cisco IOS 이미지: 쓰지 않습니다. 허용 근거를 확인하지 못했습니다.
  • FRRouting: 3차에서 메모리와 필요 권한을 직접 잰 뒤 도입 여부를 결정합니다.

아래가 모두 성립하면 B1이 낫습니다.

  • OSPF 같은 Dynamic Routing이 MVP에 반드시 들어가야 한다.
  • 사용자가 신원이 확인된 사람으로 한정되고, 팀이 서버 운영 위험을 받아들인다.
  • 개발 기간이 4주보다 길다.
  • FRR 컨테이너의 실제 메모리 사용량을 재서 서버 한 대에 들어가는 것을 확인했다.

나중에 서버에서 실행되는 장비를 붙일 수 있도록, 화면은 엔진의 공개 인터페이스만 알게 설계했습니다.

MVP 범위

로그인해 PC, Switch, Router로 토폴로지를 만들고, CLI로 VLAN과 Static Routing을 설정하고, ping의 과정과 실패 원인을 재생하며 봅니다.

포함

  • Google 로그인, 로그아웃
  • 토폴로지 목록, 생성, 복제, 삭제, 자동 저장
  • 편집기: 장비 추가·이동·삭제, 링크 연결·삭제
  • 장비: PC, Switch, Router, 인터페이스 켜기·끄기
  • 콘솔과 CLI
  • IP 설정과 검증
  • Switching, ARP, 루프 보호
  • VLAN: 생성, access, trunk
  • IPv4 전달, Static Routing, ICMP 오류
  • ping
  • 추적, 이벤트 목록, 단계별 재생, 프레임 열람
  • 포트 상태 표시, 장비 테이블 보기
  • 오류 피드백과 통신 실패 사유
  • 내보내기, 가져오기, 예제 3종

기능 요구사항 47개, 비기능 요구사항 12개로 정리되어 있습니다. 한 토폴로지의 한도는 장비 50대, 링크 100개입니다 가정

매일 암호화한 백업을 서버 밖에도 복사합니다. 테스트용 로그인 경로는 로컬 주소에서만 켜집니다. 배포 경로(CI, 배포 키)를 보호합니다.
