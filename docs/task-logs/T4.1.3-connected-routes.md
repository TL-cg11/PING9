## 1. 목표와 완료 기준

- [x] IP가 있고 실제 포트 상태가 up인 인터페이스만 직접 연결 경로에 포함.
- [x] 포트·IP·링크 변경, load에 따라 스냅샷과 CLI 갱신.
- [x] `show ip route`에 C, 네트워크/접두사, 인터페이스 표시.
- [x] `show ip interface brief`의 기존 IP 표시 유지.
- [ ] PR과 팀원 검토.

## 2. 진행 방식

1. IP·마스크에서 네트워크 주소를 구하는 공통 함수를 추가했다.
2. 순수 함수 `connectedRoutes(config, ports)`로 경로를 계산한다. Document를 고치거나 패킷을 전송하지 않는다.
3. 현재 computeViews와 CLI에 연결했다. 새 Document마다 계산하므로 이전 테이블이 남지 않는다.
