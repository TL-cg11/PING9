## 2. 진행 방식

기존 오른쪽 아래 손잡이를 8방향 손잡이로 확장했다. 포인터 이동과 방향키 입력은 같은 resizeWindow 계산을 사용한다.
왼쪽·위쪽에서는 위치와 크기를 함께 변경하고 반대편 변은 고정한다. 창의 기본 최소 크기는 300×160이며 배치 영역이 더 작으면 영역 크기를 따른다.

휠 이벤트는 SVG에만 passive:false로 등록했다. deltaMode를 정규화하고 한 이벤트의 배율 변화를 제한한다.
휠 확대는 포인터를 기준으로 viewBox를 조정하며 기존 버튼과 배율 상태·한도 25~300%를 공유한다.
장비·화면 드래그 중에는 휠 확대를 적용하지 않는다. 터미널·설정 패널·확대 버튼 영역은 SVG의 형제이므로 내부 스크롤과 섞이지 않는다.
