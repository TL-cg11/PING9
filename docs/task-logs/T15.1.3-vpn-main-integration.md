실제 Chrome의 새 IPsec 예시 탭에서 다음을 확인했다.

```text

PC_A> ping -n 1 192.168.2.10

```

브라우저에서는 IPsec 통신과 화면 공존을 확인했다. GRE·양방향·장애 행렬·파일 왕복은 자동 통합 테스트로 검사했다.
