## 2. 진행 방식

수정 전 재현 테스트를 먼저 작성했다. 기존 PC 순환 테스트는 통과했으나 Router 출발 테스트는 TTL 문구가 없어서 실패했다.
화면 테스트도 기존 경로를 그대로 호출하면 15초 한도를 초과했다 (기본 케이블 시간 기준 Router 회차 72.1초, PC 회차는 더 김).

원인은 Router가 생성한 ICMP 오류의 목적지가 자기 주소인 경우에도 다음 홉 조회·ARP 송신을 했기 때문이다.
오류 원래 출발지가 활성화된 자기 인터페이스 주소이면 ICMP_ERROR_SENT와 ICMP_ERROR_RECEIVED를 로컬 기록하고 링크로 내보내지 않는다.
다른 장비로 반환하는 기존 경로는 그대로 유지한다.

화면은 같은 frameId가 같은 방향의 링크를 통과하는 최초 두 번과 마지막 통과만 남긴다.
모든 폐기와 ICMP 오류의 귀환은 유지하고, 원본 Trace는 변경하지 않는다. 축약된 이동 수를 캔버스에 표시한다.
긴 케이블·긴 경로에서도 대기 시간이 늘지 않도록 화면 시간에만 15초 상한을 적용한다.
정상적인 짧은 ping의 걸음·시간은 바꾸지 않는다.
