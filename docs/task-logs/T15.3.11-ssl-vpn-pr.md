## 3. 포함 범위와 남은 범위

- 포함: PC의 vpn connect/disconnect/status, Router endpoint, 실 경로를 지나는 교육용 TCP 제어 메시지, 이름/CA/사용자 식별자 일치 검사, 풀/접속 상한/가상 만료/해제/설정 변경 처리.
- 포함: 기존 HTTP/FTP TCP와 별도 세그먼트 호환, Server PC INPUT/OUTPUT 규칙, 교육용 TCP 패킷 카드·이벤트/재생.
- 포함: R1/R2/R3 SSL·GRE·IPsec 실습 안내, 가져오기 JSON, 주소 선택·명령 뜻·프롬프트·적용/취소 절차, 사용자 사진 주소용 GRE 안내.
- 남음: 실제 TLS·암호학적 인증·암호화·TCP handshake/재전송, SSL 내부 ICMP 데이터 터널, 설정 화면과 Router SSL 설정 CLI. 현재 설정은 JSON/내부 Command로 입력한다.
