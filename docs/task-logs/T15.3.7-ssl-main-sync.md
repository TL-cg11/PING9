## 3. 변경 내용

- main이 삭제한 Firewall 모델/종류를 복원하지 않았다. SSL의 완성 예제를 PC_A → ISP → R2 → R1 → PC_B로 바꿔 사용자 실습 가이드와 주소 계획을 맞췄다.
- SSL 선행 TCP를 최신 Ipv4Host의 송수신 경로로 연결해 Server PC INPUT/OUTPUT 필터를 우회하지 않도록 했다. 기존 서비스 패킷은 기존 방식 그대로 동작하며, 교육용 TCP만 IPv4 protocol 6과 지정 TTL을 추가한다.
- REJECT는 배열형 RST에도 응답하지 않아 기존 TCP RST 무응답 의미를 유지한다.
- 삭제된 독립 Firewall을 쓰던 로컬 테스트는 Router 경로와 Server PC 필터로 옮겼다. R2 경로 중단/복구, Server PC OUTPUT/INPUT 차단·복구, SYN/RST REJECT를 검증한다.
- 새 패킷 카드에 교육용 TCP 이름·색·flag 배열 표시를 연결하고 실제 SSL trace로 렌더링 검증한다. main의 카드 일시 정지·닫기·보기 메뉴를 보존한다.
- SSL 안내서의 예제·IP·포트 중단 실습·테스트 설명을 현재 구조로 갱신했다.
