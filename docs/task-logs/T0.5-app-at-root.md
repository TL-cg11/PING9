## 1. 목표와 완료 기준

T0.3에서 운영 첫 주소(`/`)가 화면 시안(`mockup.html`)을 보여 주게 했다. 편집기 화면(T5.4.1)이 `main`에 들어왔으므로 첫 주소가 그 화면을 보여 주게 되돌린다.

- [ ] https://ping9.vercel.app 에서 편집기 화면이 열린다 (병합 뒤 확인)
- [ ] https://ping9.vercel.app/mockup.html 에서 시안이 열린다 (병합 뒤 확인)
- [ ] 이 PR의 미리보기 배포에서 위 두 가지를 확인한다 (로그인이 필요해 명령으로는 확인하지 못함, 4절)
- [x] lint, 타입 검사, 단위 테스트, 빌드가 통과한다
- [ ] 다른 사람이 Pull Request를 검토했다

## 2. 진행 방식

1. `vercel.json`의 `routes`를 지웠다. T0.3 기록 문서가 적어 둔 되돌리는 방법 그대로다 ("앱을 첫 화면으로 되돌릴 때는 `vercel.json`의 `routes`를 지운다").
2. 빌드 결과물과 React 앱, `apps/web/public/mockup.html`은 건드리지 않았다.

### 주요 결정

| 결정 | 이유 | 버린 대안 |
|---|---|---|
| `routes`를 통째로 지움 | `/` 규칙이 없으면 빌드 결과물의 `index.html`이 나온다. 앱에 클라이언트 경로가 아직 없어 다른 규칙이 필요 없다 | `/` 규칙만 지우고 `/mockup.html`의 404 규칙은 남김: 시안이 운영 주소 어디에서도 보이지 않게 됨 |
| `apps/web/public/mockup.html`은 지우지 않음 | 편집기 화면은 아직 시안의 일부만 구현했다 (하단 패널, 실패 알림, 펭귄 등이 없음). 남은 화면을 만들 때 시안을 계속 본다. 시안은 `/mockup.html`에서 열린다 | T0.3이 적어 둔 대로 시안 파일도 지움: 화면이 시안을 다 덮은 뒤에 팀이 정한다 |
