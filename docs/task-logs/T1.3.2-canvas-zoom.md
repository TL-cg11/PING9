## 1. 목표와 완료 기준

- [x] 사용자 요청대로 캔버스 우측 하단에 `+`, `−` 버튼을 둔다.
- [x] 화면 중심을 유지하며 25% 단위로 25~300% 배율을 조절한다.
- [x] 현재 배율을 표시하고, 범위 끝에서 해당 버튼을 비활성화한다.
- [x] 확대 상태의 장비 드래그 배치·이동과 포트 선택 연결이 동작한다.
- [ ] PR과 팀원 검토.

## 2. 진행 방식

1. 기존 캔버스의 SVG viewBox와 배율을 화면 상태로 관리한다. Document의 장비 좌표나 링크는 확대·축소할 때 바꾸지 않는다.
2. SVG의 실제 보이는 영역을 계산해 중심을 고정한다. 가로·세로 여백이 있는 화면에서도 확대·축소 후 중심이 이동하지 않는다.
3. 장비를 끌고 있는 동안 배율 버튼을 비활성화한다. 포트 팝업은 배율이 바뀐 뒤 현재 화면 좌표로 다시 배치한다.
4. 기존 `getScreenCTM()` 역변환을 그대로 사용해 확대된 화면에서도 드롭 좌표를 계산한다.

### 주요 결정

| 결정 | 이유 | 버린 대안 |
|---|---|---|
| SVG viewBox 변경 | 장비, 케이블, 포트 표시를 같은 배율로 조절하고 좌표 변환을 유지 | 앱 전체 CSS 확대 |
| 25~300%, 25% 간격 | 작은 전체 구성부터 세부 연결까지 일정한 단계로 조절 | 제한 없는 배율 |
| 같은 T1.3.2 브랜치에 후속 기록 | 앞선 드래그 편집 작업의 후속이며 아직 PR 전 | 기존 변경을 분리해 이동 |

실제 Chrome 검증은 별도 로컬 탭에서 수행했다. 사용자가 작업 중인 기존 탭의 실습은 변경하지 않았다.

- `+`를 눌러 100 → 125 → 150%, 300%까지 확대. 300%에서 확대 버튼 비활성화 확인.
- `−`를 눌러 25%까지 축소. 25%에서 축소 버튼 비활성화 확인.
- 125%에서 Router를 원하는 위치에 끌어 놓아 장비 수 6 → 7 확인.
- R1 Gi0/0 → SW1 Fa0/3 포트 선택으로 케이블 생성 확인.
- 125%에서 연결된 라우터를 이동한 후 300 → 25 → 100%로 조절해도 위치와 연결이 유지됨을 확인.
- 우측 하단 고정 컨트롤과 배율 표시를 화면으로 확인.
