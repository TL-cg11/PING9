## 1. 목표와 완료 기준

- 최신 메인 b41a7bd의 Switch 전달·MAC 학습과 Router 전달·ARP·ICMP 응답을 함께 사용한다.
- Switch 2대와 Router 1대·2대 구성에서 양방향 ping, 장애·복구를 검사한다.
- 공통 ping 판정·통계에 ICMP 오류를 포함하여 화면의 출력 간격·Ctrl+C와 일치시킨다.

## 2. 진행 방식

runtime.ts와 views.ts의 양쪽 변경을 보존했다. 한쪽 파일 전체 선택은 다른 장비 모델을 없애므로 사용하지 않았다. 세 장비 모두 구현되어 더 이상 도달할 수 없는 MissingModel과 미지원 Router용 실행 복구 처리는 제거했다. Switch 자체 checkpoint API는 변경하지 않았다.

## 3. 변경 내용

- Runtime에 PC·Router·Switch 모델, 초기화, 설정 변경, ARP·MAC 조회를 함께 등록.
- views의 peer-down 상태 계산과 직접 연결·정적 경로 계산을 함께 유지.
- shared ping 분류·통계에 ICMP 오류를 추가하여 engine과 web이 같은 규칙 사용.
- 자동 병합 뒤 남은 ping 출력의 사라진 카운터 참조 수정.
- Router 미구현을 전제한 예전 테스트는 IP 없는 Router의 ARP 실패와 Switch 학습 유지 검사로 변경.
- shared 예시에 Switch를 삽입하는 함수와 PC—SW1—R1—R2—SW2—PC 자료 추가.
- 새 switched-router-lab.test.ts: 양방향 ping, TTL 127·126, Router ping·ARP, Switch MAC 학습, 포트 종료·VLAN 차단·복구, 경로 없음 오류·복구.
