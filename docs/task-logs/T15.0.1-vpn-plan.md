## 2. 진행 방식

2026-11-11에는 GRE/IPsec/GRE over IPsec 세 모드를 초안으로 작성했다.
2026-11-12 사용자가 GRE+IPsec을 제외하고 GRE·IPsec부터 구현하도록 요청했으므로 미커밋 초안을 새 범위로 고쳤다.
이어 사용자가 실제 암호화 없는 교육용 시뮬레이션을 선택했다.
기존 확정 계획서는 고치지 않고 별도 제안 문서에 작성했다.

## 3. 변경 내용

[GRE·IPsec 계획](../proposals/vpn-gre-ipsec.md): 구현 순서, 논리/물리 경로, 수동 SA/selector/sequence/lifetime 계약, 고정 실습 구성, 범위와 검증.
구현 결과는 [T15.1.1 기록](T15.1.1-vpn-gre-ipsec.md)에 따로 남긴다.

## 4. 결과와 검증

상대 링크 검사와 git diff --check를 실시한다. 기능 코드 검증은 T15.1.1에 기록한다.

## 5. 추정과 실제

이전 세 모드 초안의 7~10인일 추정은 새 범위의 확정 일정으로 사용하지 않는다. 실제 인일은 측정하지 않았다.

## 6. 계획과 달라진 점

사용자의 최신 요청에 따라 두 모드로 변경했다. 상위 확정 로드맵 본문은 팀 합의 전까지 유지했다.

## 7. 남은 일

팀원 리뷰와 실제 일정 배정. SSL VPN의 구현 여부/범위는 추후 결정한다. push·PR은 하지 않았다.
