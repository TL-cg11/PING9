## 1. 목표와 완료 기준

팀이 함께 볼 수 있도록 편집기 화면 시안(HTML 한 파일)을 운영 주소에 올린다.

- [x] 시안이 https://ping9.vercel.app/mockup.html 에서 열린다
- [x] 첫 화면(`/`)과 기존 빌드는 바뀌지 않는다
- [x] 검색 엔진에 노출되지 않는다 (`noindex`)
- [ ] 공통 완료 조건의 리뷰: 사용자 지시로 검토 없이 병합

## 2. 진행 방식

1. 시안 파일 `ping9-3.html`을 `apps/web/public/mockup.html`로 복사했다.
2. `<meta name="robots" content="noindex">`를 추가했다. 나머지 내용은 원본 그대로다.
3. `pnpm --filter @ping9/web build`로 빌드해, `dist/mockup.html`이 원본과 같은지 확인했다.

### 주요 결정

| 결정 | 이유 | 버린 대안 |
|---|---|---|
| `apps/web/public/`에 둠 | Vercel은 Vite 빌드 결과(`apps/web/dist`)만 배포한다. `public/`의 파일은 빌드할 때 그대로 복사된다 | `apps/web/index.html` 덮어쓰기: Vite 진입 파일이라 빌드가 깨짐 |
| 별도 주소 `/mockup.html` | 시안의 터미널은 명령을 실행하지 않고, 패킷 흐름은 고정 데이터다. 첫 화면으로 쓰기에는 이르다 | 첫 화면 교체 |

## 6. 계획과 달라진 점

- 계획에 없던 작업이다.
- 시안의 PC 콘솔은 MVP의 PC 명령(`ipconfig`, `ping`)만 보여 준다. Windows·Linux PC 설계 논의는 아직 계획 문서에 반영되지 않았다.
