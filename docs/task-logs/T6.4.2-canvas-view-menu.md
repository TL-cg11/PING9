## 1. 목표와 완료 기준

캔버스의 글자가 많아 장비와 케이블이 가려진다. 보고 싶은 글자만 골라 켜고, Router 포트 주소는 끝자리 대신 전체로 읽게 한다.

- [x] 캔버스 오른쪽 위 "보기" 메뉴: 대역, 포트 주소, 포트 이름, VLAN 표시, 장비 이름 아래 IP를 체크로 켜고 끔
- [x] 맨 위 "전체": 모두 켜져 있으면 모두 끄고, 하나라도 꺼져 있으면 모두 켬. 일부만 꺼지면 가로줄 표시
- [x] 고른 값은 브라우저에 기억 (`ping9.canvasView`)
- [x] Router 포트 주소를 끝자리(`.1`) 대신 `192.168.10.1/24`로. PC 쪽 케이블에는 주소를 쓰지 않음 (이름 아래에 이미 있음)
- [x] 포트 주소 글자를 10px에서 9px로 줄이고, 장비 아이콘보다 앞에 그림
- [x] 공통 완료 조건: lint, 타입 검사, 단위 테스트, 빌드 통과. 리뷰는 PR에서

## 2. 진행 방식

1. 디자인 사본(5180)의 사본을 다른 포트로 띄워 시안을 만들었다. 대역 켜기·끄기는 네 가지 안(확대·축소 옆 스위치, 확대·축소 막대 안 버튼, "보기" 메뉴, 칩을 눌러 접기)을 실제 화면에 끼워 넣어 비교했고, 사용자가 "보기" 메뉴를 골랐다.
2. 5180에 구현해 headless Chrome으로 메뉴를 열고 항목을 끄고 "전체"를 눌러 캡처로 확인했다.
3. 저장소 main에서 브랜치를 만들어 5180의 이번 변경만 diff로 옮기고 테스트를 더했다.

### 주요 결정

| 결정 | 이유 | 버린 대안 |
|---|---|---|
| "보기" 메뉴에 여러 항목 | 대역만이 아니라 다른 글자도 같은 곳에서 끈다 | 대역 하나만 켜고 끄는 스위치·버튼 |
| 끈 글자는 CSS로 숨김 (`.topo.hide-*`) | 자리 계산(겹치면 주소를 포트 밑으로)은 그대로 두고 보이기만 바꾼다 | 그리지 않기 (자리가 바뀌어 다른 글자가 움직임) |
| PC 쪽 케이블에 주소를 쓰지 않음 | 장비 이름 아래의 주소와 같은 값이 두 번 보인다 | PC 쪽도 전체 주소 |
| 포트 주소를 장비 아이콘 앞에 | 전체 주소가 길어져 아이콘에 가려졌다 | 케이블 글자 층 그대로 |
