## 2. 진행 방식

1. 5180에서 시안을 고쳐 가며 사용자가 정했다 (2026-11-12).
2. 빈 카드 그림은 사용자가 준 원본(1536×1024)에서 펭귄과 말풍선이 들어가는 사각형(가로 150 ~ 1500, 세로 110 ~ 990)을 줄이지 않고 잘랐다(1350×880). 처음에 720px로 줄였더니 넓힌 패널과 레티나 화면에서 흐려 보여서 원래 크기로 바꿨다.
3. 눈밭 마스크는 배경 그림과 같은 크기(1586×992)의 흑백 알파 그림이다. 색(채도)으로 바다를 자동 판별해 봤지만 눈밭 위 얼음의 그림자까지 바다로 잡혀 경계가 들쭉날쭉했다. 그래서 지평선과 얼음 덩어리·바다 윗선을 따라 다각형을 손으로 정하고 10px 흐리게 했다.
4. 격자는 `.app`의 `::before` 층에 그리고 마스크를 배경과 같은 방식(`cover`, 아래 가운데)으로 맞췄다. 그래서 창 크기가 바뀌어도 마스크가 그림의 눈밭 자리를 따라간다.
5. 패널 폭은 `app.tsx`가 `.work`의 `grid-template-columns`로 정한다. 손잡이는 `.work` 안에 절대 위치로 두어 패널 컴포넌트는 건드리지 않았다.
6. `pnpm check`를 돌리고, `vite preview`로 빌드를 띄워 헤드리스 Chrome으로 확인했다 (4절).

### 주요 결정

| 결정 | 이유 | 버린 대안 |
|---|---|---|
| 격자를 눈밭에만 | 하늘과 바다 위의 점이 그림을 해친다는 사용자 결정 | 격자 없음(A안), 캔버스 전체에 격자 |
| 마스크 경계는 손으로 정한 다각형 | 색 판별은 얼음 그림자를 바다로 잡는다 | 채도 기준 자동 판별 |
| 격자를 캔버스가 아니라 `.app` 층에 | 마스크를 배경 그림과 같은 기준(창 전체)으로 맞춰야 한다. 점의 시작은 캔버스 왼쪽 위(140, 70)로 맞춰 실시간과 같은 자리에 찍힌다 | 캔버스 배경에 격자 (마스크가 그림과 어긋남) |
| 폭 범위 270 ~ 560px | 270은 지금 폭. 그보다 넓으면 캔버스가 너무 좁아진다 | 제한 없음 |
| 빈 카드 제목을 뺀다 | 말풍선이 이미 인사를 해서 인사가 두 번 나온다 (시안 B안) | 제목 유지(A안) |

`vite preview`(빌드 결과)를 헤드리스 Chrome으로 열어 확인했다.

- 1440×860, 1920×1080 두 크기에서 시뮬레이션 격자가 눈밭에만 보이고, 캔버스 왼쪽 위가 (140, 70)으로 점의 시작과 같다.
- 손잡이가 있고, 빈 카드 그림의 `alt`가 "네트워크 탐험을 시작해 볼까요?", 제목이 없다.
- 손잡이 끌기(5180에서): 왼쪽으로 150px 끌면 패널 420px, 캔버스 1002 → 852px. 끝까지 끌면 560px에서 멈춤. 새로고침 뒤에도 560px. 두 번 누르면 270px. ← 키 한 번에 280px.
- 콘솔 오류 없음.

## 7. 남은 일과 다음 Task에 전할 것

- 배경 그림을 다시 바꾸면 눈밭 마스크도 새로 만들어야 한다. 마스크는 지금 그림의 눈밭 모양에 맞춘 것이다.
- 장비 목록 폭(112px)이나 위쪽 막대 높이(64px)를 바꾸면 격자 시작점(`background-position: 140px 70px`)도 같이 고친다.
- 그림 두 장(빈 카드 1.7MB, 배경 1.3MB)이 PNG라 크다. 화질을 거의 그대로 두고 줄이려면 WebP로 바꾸는 방법이 있다.
- 배경 원본이 1586px 폭이라 1920px 같은 큰 화면에서는 조금 흐리다. 더 선명하게 하려면 2,000 ~ 2,600px 폭 원본이 필요하다.
- 이벤트 목록(T1.9)이 오른쪽 패널에 들어가면 같은 폭을 쓴다.
