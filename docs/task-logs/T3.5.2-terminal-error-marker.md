## 2. 진행 방식

`terminal-state.test.ts`에 테스트 4개를 먼저 쓰고(2개 실패) 구현했다.

engine은 오류 줄에 `position`(입력한 줄에서 틀린 단어가 시작하는 자리)을 담아 준다. 화면은 입력 줄 바로 아래에 `^` 줄을 하나 더한다. `^`의 자리는 "프롬프트의 길이 + 공백 1 + `position`"이다.

```text
SW1(config)# vlan 5000
                  ^
VLAN 번호는 1~4094여야 해요: 5000
```

### 주요 결정

| 결정 | 이유 | 버린 대안 |
|---|---|---|
| `^` 줄을 화면 기록의 한 줄(`marker`)로 둠 | 화면 기록은 줄의 목록이다. 순수 함수(`received`)에서 만들어 테스트할 수 있다 | 입력 줄 안의 글자에 밑줄 |
| 위치가 없는 오류에는 `^` 줄이 없음 | 끝나지 않은 명령어, 실행 중에 reducer가 거부한 오류는 가리킬 단어가 없다 | 줄의 끝을 가리킴 |
| 입력 줄의 글을 공백 그대로 그림 | 전에는 이어진 공백이 하나로 보였다 (T5.4.1 기록 7절). `^`와 위치가 어긋난다 | 그대로 둠 |
| `^` 줄의 색은 오류의 색 | 오류 설명과 한 덩어리로 보인다 | 보통 글의 색 |
