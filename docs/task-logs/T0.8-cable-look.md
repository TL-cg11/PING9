## 1. 목표와 완료 기준

계획에 없는 Task라 완료 기준을 새로 정했다. 그림은 사용자가 준 케이블 그림 5가지(기본 눈길, 금 간 얼음, trunk 넓은 길, 발자국, 얼음 다리)를 따른다.

- [x] 기본 링크는 하늘색 테두리의 흰 길. access VLAN이 1이 아니면 테두리가 그 VLAN 색이고 길 위에 "VLAN 10"을 쓴다
- [x] 한쪽 포트라도 꺼져 있으면(`adminUp: false`) 회색 마디로 끊긴 길과 가운데의 금
- [x] trunk는 넓은 길 위에 VLAN 색 차선. 한 끝이 허용하지 않는 VLAN의 차선은 그 끝 앞에서 막히고 빨간 ✕. 전체 허용이거나 VLAN이 5개 이상이면 무지개
- [x] Router끼리는 위로 휜 초록 다리와 그 아래 바다 물결
- [x] 아이콘 뒤의 좁은 타원 받침. 선은 타원 테두리에서 끝나고 나팔처럼 벌어지는 이음목으로 이어진다
- [x] 알약 표시("VLAN 10", "trunk")를 없애고 글자를 길 위에 길 방향으로 쓴다
- [x] 드래그·연결 도구·확대(T1.3.2)와 함께 동작한다. 드래그 중에는 타원과 길이 장비를 따라간다
- [x] lint, 타입 검사, 단위 테스트, 빌드 (`pnpm check`)
- [ ] 리뷰
- 발자국(Trace 재생 중 지나간 길)은 재생 화면(E6)으로 넘겼다

## 2. 진행 방식

1. 그림은 저장소 밖의 로컬 사본(5180 포트)에서 먼저 그려 보고 시안 그림으로 정했다: 타원 받침(B-3d), 케이블과 타원의 이음(C), trunk 두께(A).
2. 그 사본은 T0.7 브랜치에서 복사한 것이었다. main에 T1.3.2(드래그 편집)가 들어오며 `canvas.tsx`가 크게 바뀌어, 3-way로 합치고 `canvas.tsx`는 main의 드래그 코드 위에 케이블 부분을 다시 얹었다. `link-ends.ts`, `editor.css`는 자동으로 합쳐졌다.
3. 무엇을 그릴지 정하는 `cableLook`은 `format/`의 순수 함수로 두고 테스트했다. 그리는 일은 `components/cable.tsx`가 한다.
4. 옛 그림을 기대하던 `canvas.test`, `link-ends.test`를 새 그림에 맞췄다.

### 주요 결정

| 결정 | 이유 | 버린 대안 |
|---|---|---|
| 길은 같은 선을 두 번 그린다 (굵은 테두리 색 위에 가는 안쪽 색) | 직선과 휜 다리에 같은 방법을 쓴다 | 길 모양 다각형을 계산 |
| 꺼짐 판단은 문서의 `adminUp: false`만 본다. 설정한 적 없는 Router 인터페이스는 켜진 것으로 그린다 | 엔진의 포트 상태는 캔버스에 아직 안 들어온다. 처음부터 모든 다리가 금 가 보이는 것을 피한다 | 실제 Cisco처럼 처음엔 꺼짐 |
| 차선은 허용 목록이 정해진 끝들의 VLAN을 모두 그린다. 막힌 차선은 허용한 끝에서 길 가운데까지 실선, 그 뒤 막은 끝까지는 흐린 점선이고, 가운데에 빨간 막대와 ✕를 길 바깥으로 세운다. 문장은 쓰지 않는다 (PR 뒤 바꿈: 처음엔 막은 끝 바로 앞에서 끊었다) | 어느 VLAN이, 어느 쪽에서 막혔는지가 그림으로 보인다. ✕가 끝의 포트 이름·허용 글자와 붙어 있지 않아 잘 보인다 (사용자 결정). 막대는 차선에서 바깥으로 서서 가운데의 trunk 글자와 겹치지 않는다 | 양쪽 공통 VLAN만, ✕를 길 한가운데에 (다른 차선까지 막힌 것처럼 보인다) |
| 전체 허용과 5개 이상은 무지개 길 (색이 길을 따라 바뀜) | 나란한 차선(그 VLAN들)과 모양이 달라 헷갈리지 않는다. 정확한 목록은 끝의 "허용 …" 글자 | 차선 여러 개 |
| trunk 두께 테두리 22 / 안 18 (시안 A) | 30 / 26은 너무 굵었다. 18 / 14는 글자가 차선에 닿는다 | 30, 18 |
| 선은 상자 대신 타원 받침 테두리에서 끝난다 (`linkEnds`) | 아이콘 아래 받침과 길이 이어져 보인다 | T0.6의 상자 경계 |
| 타원 테두리는 mask로 길 안쪽이 들어오는 자리만 지운다 | 길이 타원 안으로 이어져 보인다 | 테두리를 길 위에 그대로 |
| 케이블 선택 표시는 아이콘의 선택 빛과 같은 파란 빛이 길을 따라 흐리게 번지고 천천히 밝아졌다 어두워진다. 길 테두리 색은 그대로 둔다 (PR 뒤 추가) | 장비와 케이블의 선택 표시를 하나로 (사용자 요청). 가로·세로 선은 상자 높이가 0이라 흐림 영역을 좌표(`userSpaceOnUse`)로 준다 | 테두리를 진한 파랑으로 바꾸고 옅은 띠 |
