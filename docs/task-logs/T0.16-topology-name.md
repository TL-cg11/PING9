## 2. 진행 방식

1. 시안을 만들어 사용자가 정했다 (2026-11-12).
2. 이름 칸을 `TopologyName` 컴포넌트로 따로 두고 `TopBar`가 `onRename`을 받으면 그린다. 이름 상태는 T7.1.2에서 만든 `app.tsx`의 `topologyName`을 그대로 쓴다.
3. 이름 규칙은 공통의 `checkTopologyName`(1~100자, 제어 문자 없음)을 그대로 쓴다. 가져오기의 검사와 같은 규칙이다.
4. 개발 서버를 띄워 헤드리스 Chrome으로 눌러 확인했다 (4절).

### 주요 결정

| 결정 | 이유 | 버린 대안 |
|---|---|---|
| 쓸 수 없는 이름으로 칸 밖을 누르면 원래 이름으로 돌아간다 | 칸 밖을 누르는 것은 그만두는 뜻일 때가 많다. 칸을 붙잡아 두면 다른 곳을 누를 수 없다 | 칸을 열어 둠 |
| 한글 조합 중의 Enter는 저장하지 않는다 | 조합을 끝내는 Enter가 저장으로 먹혀 마지막 글자가 빠진다 | 그대로 저장 |
| 이름이 그대로면 `onRename`을 부르지 않는다 | 바뀐 것이 없다 | 늘 부름 |
| 이름은 단추(`button`)로 그리고 Tab으로도 닿는다 | 키보드로도 고칠 수 있게 | 글자에 클릭만 |
| 이름은 기억하지 않는다 (새로고침하면 "새 토폴로지") | 장비도 새로고침하면 사라진다. 저장은 내보내기로 한다 | `localStorage` |
