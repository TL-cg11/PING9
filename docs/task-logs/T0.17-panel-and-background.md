## 1. 목표와 완료 기준

디자인 사본(5180)에서 사용자가 정한 화면을 저장소에 옮긴다. 시안은 `T0.17-시안-배경.png`, `시안-시뮬레이션배경.png`.

- [x] 좌우 패널(장비 목록, 속성 패널)이 화면 가장자리에서 떨어진 둥근 카드. 반투명 흰색, 그림자
- [x] 장비를 고르지 않았을 때 속성 패널에 빈 카드: 펭귄 그림, "관제 준비 완료!", 장비 수 / 50, 네트워크 상태(장비가 없으면 "비어 있음", 있으면 "대기 중")
- [x] 캔버스 빈 곳을 누르면 고른 장비·케이블이 풀린다
- [x] 시뮬레이션 모드에서만 창 전체에 오로라 그림. 상단 막대는 반투명, 캔버스 점 격자는 끈다 (그림에 ＋ 격자가 있음)
- [x] 실시간 모드는 지금 화면 그대로 (그림 없음, 파란 상단 막대, 점 격자)
- [x] 공통 완료 조건: lint, 타입 검사, 단위 테스트, 빌드 (4절). 리뷰는 PR에서

## 2. 진행 방식

1. 5180에서 시안을 고쳐 가며 사용자가 정했다 (2026-11-11 ~ 2026-11-12).
2. 배경 그림은 사용자가 준 화면 그림에서 장비, 케이블, 펭귄, 좌우 패널, 상단 단추, 안내 막대, 확대 단추를 지워 만들었다. 지운 자리는 옆의 같은 무늬(격자 칸 단위로 옮김, 얼음덩이는 거울처럼)로 채웠다.
3. 모드를 CSS에서 나누려고 창(`.app`)에 `mode-realtime`·`mode-simulation` 클래스를 붙였다.
4. `vite preview`로 빌드를 띄워 헤드리스 Chrome으로 확인했다 (4절).

### 주요 결정

| 결정 | 이유 | 버린 대안 |
|---|---|---|
| 배경 그림은 시뮬레이션에만 | 실시간은 그림 없이 지금 화면이 낫다는 사용자 결정 | 두 모드 모두 그림 |
| 그림은 `public/`에 두고 CSS `url()`로 | 화면 크기에 맞춰 `cover`로 채운다. 번들에 넣지 않는다 | `import`로 번들에 넣기 |
| 시뮬레이션에서는 캔버스 격자를 끈다 | 그림에 ＋ 격자가 있어 겹친다 | 둘 다 보임 |
| 빈 카드의 펭귄은 PNG 한 장 | 시안 그대로. 상태별 그림은 따로 정한다 | 상태별 SVG |
