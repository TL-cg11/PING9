## 2. 진행 방식

현재 main `8990aab`의 Document, Trace, PC/Router, Runtime, Firewall 필터, 기존 VPN 계획을 확인했다. VyOS 1.4 OpenVPN 공식 문서와 TLS 참고 규격을 읽고 실제 제품 문법과 PING9 자체 모델을 분리했다.

교육용 구현 수준은 기존 IPsec 합의를 참고한 추천 기본안이다. 사용자가 SSL VPN의 실제 암호화 수준까지 확정한 것으로 해석하지 않는다. 실제 TLS가 필요하면 별도 설계로 전환하는 조건을 명시했다.

## 6. 계획과 달라진 점

기존 프로젝트 계획 본문은 수정하지 않았다. GRE/IPsec에서 제외됐던 SSL VPN을 사용자 요청에 따라 별도 제안 문서로 구체화했다. 선행 TCP/Firewall 처리, 자체 접속 CLI, 교육용 신뢰/인증은 제안이며 실제 TLS/OpenVPN을 구현한 상태가 아니다.
