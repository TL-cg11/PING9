## 1. 목표와 완료 기준

- [x] 자기 인터페이스 IP에 온 echo 요청에 응답(T4.2.1 모델).
- [x] Router `ping <IP>`의 출발 인터페이스 자동 선택.
- [x] `show arp`에 IP·MAC·포트 표시.
- [ ] PR과 팀원 검토.

## 2. 진행 방식

Runtime의 RouterModel도 ping 시작과 성공 판정을 지원한다. 선택한 출력 인터페이스의 IP를 출발지로 사용하고 TTL은 64다. 자기 IP/127.x는 링크 없이 응답한다. Router 모델은 Runtime에 남아 ARP를 재사용한다.

| 결정 | 이유 | 버린 대안 |
|---|---|---|
| 4회 고정, 회차별 결과와 추적 표시 | 기존 PC의 실행·추적 방식을 재사용 | 실제 OS 프로세스 실행 |
| 읽기 쉬운 회차별 문장 | 세부 TTL·시간과 실패를 확인 | IOS의 느낌표만 출력 |

## 3. 변경 내용

RouterModel의 sendEcho/repliesReceived, Runtime의 출발 모델 선택, Router network-commands와 테스트를 추가했다.

## 6. 계획과 달라진 점

Router 콘솔은 IOS 명령 문법과 회차별 설명 출력을 사용한다. ping 횟수 옵션은 이번 범위에 추가하지 않았다.
