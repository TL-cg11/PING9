## 1. 목표와 완료 기준

[T0.2](T0.2-ui-mockup-page.md)에서 올린 화면 시안을 운영 첫 주소에서 바로 보이게 하고, 시안의 별도 주소는 없앤다.

- [ ] https://ping9.vercel.app 에서 시안이 열린다 (주소창은 그대로)
- [ ] https://ping9.vercel.app/mockup.html 은 404
- [ ] 공통 완료 조건: PR 검사(`check`) 통과

## 2. 진행 방식

1. `vercel.json`에 `routes`를 넣어 `/` 요청을 `mockup.html`로 내보내고, `/mockup.html`을 직접 요청하면 404를 돌려주게 했다.
2. 빌드 결과물(`apps/web/dist`)과 React 앱은 건드리지 않았다.

### 주요 결정

| 결정 | 이유 | 버린 대안 |
|---|---|---|
| `routes` 사용 | `routes`는 실제 파일보다 먼저 처리된다. `/`에 `index.html`이 있어도 시안을 내보낼 수 있다 | `rewrites`: 실제 파일이 우선이라 `/`가 바뀌지 않음. `redirects`: 주소창이 `/mockup.html`로 바뀌고, 그 주소를 없애라는 요청과 맞지 않음 |
| React 앱 진입 파일은 그대로 둠 | 팀이 만드는 앱의 빌드 구조를 바꾸지 않는다. 되돌릴 때는 `routes`만 지우면 된다 | 시안을 `index.html`로 바꾸고 앱을 다른 파일로 옮기기 |
