## 2. 진행 방식

장비 순서는 화면의 상태로만 보관하여 Document의 장비·연결 정보는 변경하지 않는다.
빈 배경 드래그는 SVG viewBox만 이동하며 장비 드래그는 기존 이동 Command를 유지한다.
글자는 별도 SVG 레이어에 그리되 포인터를 통과시켜 장비와 케이블 선택을 막지 않는다.

터미널은 캔버스의 CSS 픽셀 좌표로 계산하고 전체 너비·높이로 경계를 제한한다.
기존 native resize 대신 포인터·방향키를 지원하는 크기 조절 손잡이를 사용하여 경계 밖 확대를 막는다.
ResizeObserver로 부모 영역 변경에 맞춰 창을 다시 맞추고 지도는 보던 중심·배율을 유지한다.
