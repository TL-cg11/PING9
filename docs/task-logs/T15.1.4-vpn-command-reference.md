## 1. 목표와 완료 기준

- [x] 실습안내서에 VPN 명령어만 따로 표로 정리.

## 2. 진행 방식

바로 앞 대화에서 확인한 vpn-mode/tunnel/ipsec CLI 정의를 기준으로 안내서 앞부분에 모드 선택·GRE 설정·IPsec 설정·상태 조회 표를 추가했다.
일반 모드 이동이나 일반 ping/조회는 표에 포함하지 않고 입력 위치만 짧게 안내했다.

## 3. 변경 내용

[실습안내서](../guides/vpn-local-lab.md)의 VPN 명령어 모음.
프로필 shutdown과 vpn mode off의 차이, 양 끝 SPI/subnet 대응, 교육용 범위를 함께 표시했다.
추가 질문을 반영해 vpn mode/no vpn mode/show vpn의 PING9 전용 여부와 단순화한 IPsec 하위 문법을 명시했다. Cisco 공식 crypto map/VTI 문서 링크로 실제 적용 방식과 구분했다. 기능 코드는 변경하지 않았다.
