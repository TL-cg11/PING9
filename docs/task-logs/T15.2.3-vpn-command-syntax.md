## 2. 진행 방식

사용자가 제시한 `set interfaces tunnel [터널 이름] encapsulation [캡슐화 방식]` 형식을 기준으로 작성했다. 대괄호와 한글 설명을 입력하지 않는다는 규칙, 각 단어의 뜻, 실제 `tun0`·`gre` 입력을 나란히 설명했다. 같은 형식을 기존 GRE·IPsec 표 전체에 적용했다.
